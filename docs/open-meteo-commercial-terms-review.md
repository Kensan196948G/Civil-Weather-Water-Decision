## 1. 本システムでの利用内容

- モジュール: `backend/app/services/data_collectors/open_meteo.py`
- 用途: 気象予報（気温・降雨・風速・突風・湿度）の**補完データ**として判定エンジンへ反映。
  公式データ（気象庁XML・環境省WBGT）を優先し、Open-Meteo は補完に使用
- 取得方式: `https://api.open-meteo.com/v1/forecast`（APIキーなし・無料エンドポイント）
- キャッシュ: 5分TTLの予報キャッシュ＋スケジューラによるウォーム（約5分間隔）
- 想定呼出量: 現場数×定周期（PoCは16現場、本番は100現場規模を想定）。
  100現場×12回/時×24h = 28,800 calls/日となり、**無料枠（10,000 calls/日）を超過する可能性**

## 3. 本システムの該当性と対応方針

本システムは社内の施工判断支援（建設会社の業務利用）であるため、**商用利用に該当する**と
判断するのが安全側です。したがって:

1. **契約要否**: 有償プラン（少なくとも API Standard）の契約要否を法務・ITで確認し、
   契約する場合は費用負担部門・予算・請求先を決定する（本確認書 §5）。
2. **帰属表示**: 現状フロントにOpen-Meteoへの帰属表示は未実装。CC BY 4.0 に基づき
   表示の追加が必要（例: フッター「気象データ: Open-Meteo (CC BY 4.0)」）。
3. **SLA**: 無料枠はSLAなし。本番の可用性要件（99%）を満たすには有償プランまたは
   代替データソースの併用を検討する。
4. **呼出量**: 100現場規模では無料枠を超過する見込み。有償プランのコール予算を設定する。
