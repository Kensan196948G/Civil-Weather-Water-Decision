# 施工判定 標準閾値 安全・技術レビュー用資料

本表は判定エンジン（`backend/app/services/decision_engine.py` / `rules.py`）の
現在の有効値（既定値＋DB上書き前）を、安全・技術部門のレビュー用に出力したもの。

レビュー完了後に、承認日・承認者・版を追記し、`DecisionRule`（DB）へ反映する。
過去判定は `decision_results.thresholds_json`（スナップショット）で当時の閾値を再現できる。

## 1. 共通閾値（会社基準・全工種共通）

| キー | ラベル | 値 | 単位 | 判定への影響 |
| --- | --- | --- | --- | --- |
| rain_light | 降雨 注意 | 1.0 | mm/h | 注意（土工・打設・舗装） |
| rain_heavy | 降雨 中止検討 | 5.0 | mm/h | 中止検討 |
| wind_strong | 平均風速 注意 | 6.0 | m/s | 注意（クレーン・打設） |
| gust_stop | 突風 中止検討 | 13.0 | m/s | 中止検討（クレーン） |
| temp_high | 高温 注意 | 31.0 | ℃ | 暑中対策の注意 |
| temp_low | 低温 注意 | 4.0 | ℃ | 低温施工の注意（打設・舗装） |
| wbgt_caution | WBGT 厳重警戒 | 28.0 | — | 熱中症の注意 |
| wbgt_danger | WBGT 危険 | 31.0 | — | 熱中症の中止検討 |
| upstream_rain | 上流雨量 注意 | 4.0 | mm/h | 水位上昇注意（河川内作業） |

※ 値は `decision_engine.DEFAULT_TH` のコード既定値（**仮値**。安全基準確定前は
  参考値として扱うこと）。本番DBの上書きがある場合は設定画面（GET /api/admin/rules）で
  実効値を確認すること。

## 2. 工種別の適用ルール

| 工種 | 適用される主要ルール |
| --- | --- |
| river（河川内作業） | upstream_rain / water_level_rising / flood_warning / rain_heavy / 気象庁警報 |
| concrete（コンクリート打設） | rain_light / rain_heavy / temp_low / temp_high / wind_strong / 気象庁警報 |
| earthwork（土工） | rain_light / rain_heavy / wind_strong / 気象庁警報 |
| pavement（舗装） | rain_light / rain_heavy / temp_low / 気象庁警報 |
| crane（クレーン） | wind_strong / gust_stop / 気象庁警報 |
| heat（熱中症対策） | wbgt_caution / wbgt_danger / temp_high |

## 3. 工種別の運用上の注意点（レビュー観点）

1. **コンクリート**: 外気温4℃以下は低温対策の目安。打設可否の追加条件
   （養生・加温設備の有無）は現場判断として残す。
2. **クレーン**: 定格荷重・ブーム長・風圧面積により許容風速は異なる。平均風速10m/sは
   一般的な目安であり、高所作業車・タワークレーンは別基準の確認が必要。
3. **河川**: 水位上昇率・氾濫注意水位までの余裕・退避時間は流域ごとに異なるため、
   河川観測所の水位基準線（氾濫注意/避難判断/氾濫危険）とセットでレビューする。
4. **WBGT**: 28/31は環境省の暑さ指数基準（厳重警戒/危険）に準拠。
   現場ごとの最寄り地点を自動選定できるまでは、単一地点の値であることを表示で明示する。
5. **警報**: 気象庁の大雨・洪水・暴風警報は工種によらずレベル2へ引き上げる。

## 5. 承認後の反映手順

1. 本表の承認版を固定（バージョン管理）
2. 管理者が設定画面（閾値管理）でDBへ反映（`DecisionRule` 行作成）
3. 反映後の実効値（GET /api/admin/rules）と承認表の一致を確認
4. 変更履歴・承認記録を本ファイルへ追記
