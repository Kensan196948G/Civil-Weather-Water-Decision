# 本番UI受入試験 実施チェックリスト（10シナリオ・3現場30日）

> Issue #119 の「Access認証後の本番画面操作と荒天時運用の実績がない」というP0指摘へ対応するための実施手順です。
> 本ファイルは**実施計画・記録テンプレート**であり、実施自体は現場・本社の協力が必要です。
> 全項目がPASSし、危険側の誤判定0件を確認した後に本番展開判断へ進みます。

## 1. 実施前提

- 対象現場: 河川内作業を含む現場2〜3件＋一般作業1件以上（計3現場以上）
- 期間: 30日間（荒天・高温を含むことを確認）
- 参加者: 現場管理者、安全担当、技術管理者、本社DX担当
- 対象範囲: ダッシュボード、現場詳細、作業判断、判断履歴、通知、レポート（CSV）
- 対象外: 自動停止命令（本システムは判断支援。最終判断は現場責任者）

3. 閾値・UI・運用ルールの改善項目と期限
4. 経営層への報告資料（実証結果・誤判定記録・残リスク）
