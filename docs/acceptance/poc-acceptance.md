# PoC 受入基準（3現場・30日間）と誤判定記録票

## 1. 目的

外部評価の「本番導入は不可だが、3現場程度の管理された実証は可」という判定に基づき、
本番候補（全面導入）へ進むための受入基準を定める。

## 2. 前提

- 対象: 河川内作業を含む現場2〜3件＋一般作業現場1件以上（計3現場以上）
- 期間: 30日間（荒天・高温を含むことを確認）
- 参加者: 現場管理者・安全担当・技術管理者・本社DX担当
- 利用範囲: ダッシュボード・判定・判断履歴・通知・レポート
- 対象外: 自動停止命令（本システムは判断支援であり最終判断は現場責任者）

## 3. 受入基準（30日間終了時に全項目PASS）

| # | 項目 | 合格条件 |
| --- | --- | --- |
| 1 | 判定の妥当性 | システム判定と現場責任者判断の不一致が重大方向（安全側から見て危険方向）0件 |
| 2 | データ欠測時の動作 | 欠測・遅延時に「確認不能（レベル3）」が表示され、「安全」と誤表示しない |
| 3 | 河川現場の運用 | 水位・雨量を手動/将来の自動取得で記録し、判定理由・出典を保存 |
| 4 | 判断履歴 | 実施/延期/中止/監視継続 の記録が100%保存され、発注者説明用に出力可能 |
| 5 | 通知 | 中止検討・確認不能の通知が当日中に確認され、未確認が放置されない |
| 6 | 可用性 | 営業時間中のダウンタイム合計が30分未満（障害時は復旧手順を実施） |
| 7 | バックアップ | 日次バックアップ成功・暗号化exportの検証・復元訓練を月1回実施 |
| 8 | セキュリティ | 不正アクセス・権限外操作・秘密情報露出なし |
| 9 | ユーザビリティ | 主要操作（ログイン→現場確認→判定→記録）を5分以内に完遂できる |
| 10 | 誤判定記録 | 下記の誤判定記録票で全件レビュー済み |

## 4. 誤判定記録票（テンプレート）

```text
| 項目 | 記入 |
| --- | --- |
| 日時 | |
| 現場 | |
| 作業種別 | |
| システム判定（レベル・理由） | |
| 現場責任者の判断（実施/延期/中止/監視） | |
| 差異の方向（安全側/危険側） | |
| 差異の原因（データ欠測/閾値/判断ミス/その他） | |
| 公式情報・現地確認の結果 | |
| 再発防止策 | |
| レビュー担当・日時 | |
```

危険側の差異（システムが「安全寄り」に出した）は即日エスカレーションし、
原因が判明するまで該当機能を運用停止する。

## 5. 終了判定と本番移行

- 全10項目PASS＋危険側差異0件で「管理された実証成功」
- その後、現場別WBGT・Entra ID・現場単位権限・河川自動取得の導入を条件に全面展開を判断
- 全面展開時は「90％代替」の各項目（SLO・当番・障害訓練・DR）を満たすこと
